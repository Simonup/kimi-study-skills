# 分轮示范：两段距离和的本质与边界

只在题目涉及“动点在直线或线段上，求到两个定点的距离和”时读取。本页是解题与教学示范，不是要求学生记住的题型标签。先独立核对位置与允许范围；学生已经看出关键关系时，从她所在的一步继续。

## 先看数学结构

检查四件事：哪个点能动；目标是否为 `PA+PB`；`A、B` 在允许直线的同侧还是异侧；`P` 能取整条直线、线段还是射线。表面上的“最短路”“将军饮马”字样不能替代这些条件。

同侧且 `P` 可取整条直线时，核心障碍是折线 `A→P→B` 不能直接当作线段 `AB`。将 `A` 关于直线 `l` 反射为 `A′`，任意 `P∈l` 都满足 `PA=PA′`，故 `PA+PB=PA′+PB≥A′B`。`A′、B` 分居 `l` 两侧，线段 `A′B` 与 `l` 的交点可取到，等号成立。这说明“反射”是把折线化成可比较的线段，不是看到最短就套的口令。

若 `P` 只能在线段或射线上，反射等式仍成立，但必须检查上述交点是否在允许范围内；越界时 `A′B` 只是不可达的下界，须重新比较允许位置。若 `A、B` 分居直线两侧，先看线段 `AB` 是否与允许范围相交；相交时直接由 `PA+PB≥AB` 取等。

## 两题分轮引导

基础题：`A=(0,2)`、`B=(4,2)`，`P` 在整条 `x` 轴上，求 `PA+PB` 最小值。首轮只问“题目里哪一个点能移动？”下一轮问“目标是哪两段长度的和？”再引导观察两定点与直线的位置。学生要求完整解答时直接给：`A′=(0,-2)`，`A′B` 交 `x` 轴于 `(2,0)`，最小值 `4√2`。

条件变化题：只把 `P` 的范围改为 `{(x,0):0≤x≤1}`。先问“这次 `P` 能在轴上的哪一段？”学生答后再问“原来求得的交点还允许取吗？”反射关系仍成立，但 `(2,0)` 越界；最小值在 `(1,0)`，为 `√5+√13`。不能只凭图断言端点最小：记 `F(x)=√(x²+4)+√((4−x)²+4)`。对 `0≤x<y≤1`，第一项增加量不超过 `(y−x)/2`，第二项减少量至少为 `3(y−x)/√20>(y−x)/2`，所以 `F(y)<F(x)`；需要完整证明时再向学生逐步展开根式有理化。

做完后只在当前对话归纳：两题共同的结构是“动点、两段和、位置限制”；变化的条件是允许范围。请学生指出反射步骤为何仍成立，以及哪一步必须新增交点检查。不自动保存卡片或学习状态。
