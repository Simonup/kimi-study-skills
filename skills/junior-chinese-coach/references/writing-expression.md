# 写作与交流：从真实材料到读者看得懂的表达

来源定位：表达目标与读写联系参照 [S1、S2、S3](sources.md)；本文件的片段均为原创教学示范。真实评分须看当前题目与本地老师批注 S0，不能用本文件给出伪精确分数。需要积累事例时读 [素材卡](material-bank.md)。

## 起笔与修改

先把题目拆成主题、文体、对象、字数和限制，再让学生用一句话说“我想让读者看见或理解什么”。没有材料时，先请学生说一段自己的经历、观察或阅读所得；不替学生编个人经历。学生要示范文章或段落时可给原创示范，并标为示范，随后解释如何换成学生自己的材料。

| 文体 | 先检查 | 第一轮修改优先项 |
|---|---|---|
| 记叙 | 有一件具体事件、关键场景和变化 | 把最关键的一个场景写细，而非全文加形容词 |
| 说明 | 说明对象、读者已有知识和组织顺序 | 补读者缺少的定义、例子或比较依据 |
| 议论 | 可争论的观点、事实或例子、两者之间的理由 | 补“例子为什么支持观点”的中间推理 |
| 口语交流 | 对象、目的、场合与时间 | 把开头和结尾改成适合听众的说法 |

学生给初稿时，先读全文想表达什么，再从结构、语言和思考深度三个视角选最影响理解的一处作第一轮修改；这三个视角用于诊断，不充当当地评分表。反馈采用`原句或原段 → 读者会在哪儿不明白 → 一种修改动作 → 短示范`。学生的叙述声音能传达真实经历时予以保留；不整篇改写成统一腔调。没有当地作文评分细则，不给伪精确分数；可写“按题意、材料、结构、语言四方面看，眼前最值得先改的是……”。

## 具体方法卡

### 记叙文从“流水账”走向场景

挑一个使人物或想法发生变化的时刻。让学生补四项中的缺口：当时做了什么、看见或听见什么、遇到什么阻力、此后有什么变化。不是四项全写；只补最能帮助读者理解变化的细节。比喻可说“镜头由远景推到关键动作”，随后展示学生原文里应放大的那一句。

### 议论文从“举例”走向“论证”

把一句例子后接上“这件事为什么证明观点”，检查中间有没有遗漏条件。反例不必每篇强加；观点过宽或论据冲突时，用一个反例帮助收窄边界。引用人物事例时核实事实与出处，未核实就换成学生亲历或明确标示的假设情境。

### 病句和语言润色

先读原句想表达什么，再判断是否真的有语义或语法问题。修改后复读，确认意思未变；存在两种通顺表达时不武断判其中一种错。润色优先解决指代不清、重复、搭配和句间衔接；不为追求“高级词”牺牲准确。

## 输出收尾

批改末尾写两行：“本次先改什么：〔具体段落/句子＋动作〕”“下次写这类作文先检查什么：〔可复用的一项自查〕”。学生只要提纲时，不强行附整篇作文；学生明确要完整原创示范时，给完整示范并标注与她个人经历无关。

## 三种文体的局部批改示范

以下“初稿”都是为展示批改方法写的模拟句，不代表真实学生作答。批改真实作文时保留学生事实与语气，只修改她实际写出的文字。

### 记叙：把关键变化写成场景

**模拟初稿：**“运动会接力时我很紧张，后来我跑完了，感觉自己长大了。”

**诊断：**读者看不到紧张发生在哪一刻，也不知道“长大”指什么变化。**修改动作：**只放大接棒的瞬间，补一个身体动作和一个决定。**短示范：**“接力棒碰到手心时，我差点松开。看见前面的跑道，我攥紧它继续冲了出去。”后文仍需由学生写明这件事为何改变了她的看法；不能仅凭这两句就写“学会担当”。

**迁移检查：**下次先找“事情发生变化的那个动作”，再决定详写什么。来源：S1 的表达目标；示范与判断为本 skill 的教学设计。

### 说明：补读者缺少的台阶

**模拟初稿：**“借书卡有三种颜色，使用起来十分方便。”

**诊断：**没有说明颜色分别代表什么，“方便”缺少依据。**修改动作：**按读者首次接触借书卡的视角，补分类标准与使用步骤。**短示范：**“在这项模拟借书制度中，蓝卡用于借小说，绿卡用于借科普书，黄卡用于借工具书。借书时先按书的类别选卡，再到对应柜台登记。”此处制度为原创假设，不冒充真实学校规定。

**迁移检查：**读者能否凭这段话完成所说明的动作？来源：S1 的交流要求；示范为本 skill 的教学设计。

### 议论：补例子与观点之间的理由

**模拟初稿：**“坚持很重要。小明每天练字，所以坚持很重要。”

**诊断：**重复观点，没有说明练字带来什么可观察的变化，也没说明变化如何支持观点。**修改动作：**补一项前后差别，再解释重复练习的作用。**短示范：**“如果练习记录显示，小明原先常把字写出格，连续练习后能较稳定地控制字的大小，这个例子就能说明：持续练习使他有机会反复发现并改正同一问题。”示范使用假设条件；没有练习记录时，不把效果写成已发生事实。

**迁移检查：**删掉“所以”后，读者能否仍从事实推出观点？来源：S1 的思维与表达目标；示范为本 skill 的教学设计。
