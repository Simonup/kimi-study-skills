# 古诗文：先通句义，再谈情感与写法

来源定位：学习范围参照 [S1](sources.md)，篇目原文、注释与异文以本轮学生教材 S0 为准；下列答题步骤是教学设计，不等于地方评分标准。

学生问诗文的时代、作者经历、典故或写作背景时，先读 [作品背景](context-background.md)：只补与眼前词句有关且已核实的信息，再让学生重读原句。背景是理解线索，不能替代语境中的词义和全篇证据。

## 文言文

按`句中位置 → 上下文语境 → 注释与前后句 → 译成通顺现代汉语 → 回代核查`确定词义。字形、现代组词或已学篇目的用法只能提供候选意思，必须回到本句验证。遇到一词多义，不背出所有义项后猜答案；先看本句的主语、动作和对象。翻译先保留人、事、否定、程度、时间与因果，再调语序，使现代汉语读得通；无法核对的专名与异文标明待核对。

答文言阅读题时，分开“原文直接说的事”和“结合语境得出的解释”。理解人物做法先梳理事件先后与人物处境，再谈评价。涉及作者、时代、典故或出处时，只有核对可靠材料后才给确定说法。

方法卡：

| 问题 | 先做的动作 | 答句顺序 |
|---|---|---|
| 解释词语 | 看该词在本句承担什么作用，再核注释 | 本句语境中的意思；必要时说明与今义不同 |
| 翻译句子 | 圈人、动作、否定、因果和特殊语序 | 通顺译文；再指出决定译法的关键词 |
| 概括人物或事件 | 找原句和事件先后 | 谁做了什么；从哪句可见；合理的判断 |

示例：“乃不知有汉，无论魏晋”中的“无论”须放回前后句读，是“更不用说”的意思；按今天常见的“无论……都……”去理解，会把句子读错。解释时说清这是**这句话里**的意义，不把它扩大为所有古文用法。

**完整词句示范，选自《桃花源记》：**题目要求翻译“乃不知有汉，无论魏晋”。学生误译“无论是汉朝还是魏晋，他们都不知道”。先定位“乃”“无论”，再接上渔人与村中人谈外部时代的情境；可译为“他们竟然不知道有过汉朝，更不用说魏晋两朝了”。误译把“无论”当作今天的条件连词，改变了句子层次。**这类题怎么写：**先写通顺译文，检查否定、时间先后和递进关系，再说明决定译法的关键词。原文字形与课本注释仍须按 S0 复核。

## 古诗词

先逐句看见了什么人、事、景，再看语气、转折、反复与诗题。鉴赏时用`诗中形象或词语 → 具体呈现的画面/动作 → 结合全诗的情感或思考`。只从意象推不出固定情绪；“月亮必然表示思乡”“落花必然表示伤春”都不成立。一个词可能有多个合理解释，比较哪种解释能覆盖全诗。

**诵读到理解：**先依词组和句意划出自然停顿，朗读后用自己的话复述画面；节奏只作帮助理解的标记，不能靠固定“几字一顿”替代句义。背会后再问“诗句里哪个词让你这样理解”，最后尝试用一句自己的话说明它能用于什么表达场景。

**诗歌赏析示范：**[《春望》原文见 S7](sources.md)：“国破山河在，城春草木深。”题目问两句呈现怎样的景象。学生若答“春天草木茂盛，城中生机勃勃”，只读到了“城春”，漏了“国破”。先把两处并列，再看“草木深”：春天来到城中，却显出荒芜。[S8](sources.md) 核实杜甫在战乱中一度困于被叛军占据的长安；这条背景帮助理解“国破”，但答句仍回到诗句：“诗句将山河仍在、春草繁生与国家破败并置，呈现战乱后都城荒凉的景象。”若题目进一步问情感，再结合全诗写诗人对国事的忧虑；题目只问景象时不堆加未问的作者生平。例答为本 skill 的教学示范，非官方标准答案。

背诵或默写用学生当前教材核对篇目、字形和标点。先闭卷回忆，回书核字，再针对易错字重写一句；不凭网络旧版篇目表宣布“必考”或“不考”。

学生要求古人第一人称讲述时，可以先用“这是帮助理解的想象叙述”标记角色段落；退出角色后列出文本可证实的内容和无史料支撑的想象部分。不能虚构确定年份、地点、对话或内心独白为史实。

## 讲解末尾的迁移句

- 这题怎么想：本句哪个词或全诗哪处转折决定理解？
- 这类题怎么写：先说字面或画面，再用诗文证据解释语境意义；只有题目问写法时才补写法和效果。
