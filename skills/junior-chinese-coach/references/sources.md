# 来源与校准：使用证据，不堆资料

| S9：[人教社《背影》作品页](https://www.pep.com.cn/xw/zt/hd/ywsd/sfsd/8s/201806/t20180629_1925933.shtml) | 核对《背影》示范中家中处境、送别与买橘子的原文 | 文内故事不能直接推出作品写成、发表时间或作者写作时心理 |

需要精确评分时，优先取本地当年的官方题目与已公开评分材料，以及老师给的该题批注。找不到公开细则就写“评分细则未核实”，只评价答案是否回应题意和有无文本证据。教材、试题和论文只摘本轮解释必需的短句，保留标题、版本、链接或页码；不要复制整章或整套试卷。

## 方法与来源怎样相连

| 本 skill 的做法 | 能支撑的材料 | 不能由来源推出的结论 |
|---|---|---|
| 从文本理解走向表达，按单元任务安排短练 | S1、S2、S3、S4、S5 | “所有阅读题都按同一模板得分” |
| 用语境和注释读古诗文、在作品中理解词句 | S1、S0 的具体教材页 | 某个词在所有古文中的唯一释义 |
| 用核实的时代、作者处境和文化背景解释具体词句 | S0、S7、S8、S9；S10 的教研方向 | 作者经历决定作品的唯一含义，或未查证的精确写作日期 |
| 记叙、说明、议论按不同表达目的修改 | S1、S2；本轮作文题与老师批注 S0 | 任一地区统一作文分档或扣分规则 |
| 原创题的题干、答案、干扰项逐项自检 | S5 的作业设计方向；本 skill 的质量控制 | 自制题等同当地中考真题 |

上表中的“本 skill 的做法”是依据课程与教材目标设计的**教学操作**，不是把官方文件逐字转换成公式。每份专项 reference 的例题标明“原创示例”或具体出处。只有从 S0 获得真实作答与老师批注后，才把某种错误归为该学生反复出现的问题；一个自编例题不能证明方法普适。

## 这份 skill 的结构借鉴

以下仓库作为**交互与文件组织参考**，不是课标、教材或统一评分权威；本 skill 的方法文字重新编写，未复制其题库或模板。

- [小智伴学·阅读解码器](https://github.com/qizhitang/xiaozhi-skills/tree/main/student/chinese/xiaozhi-chinese-reading-decoder)：借鉴“读懂文本后再写规范答案”和按实际作答诊断错因；不沿用“分值等于要点数”的推断。
- [小智伴学·教师端阅读指导](https://github.com/qizhitang/xiaozhi-skills/tree/main/teacher/chinese/xiaozhi-teach-chinese-reading-guide)：借鉴字面理解、写法分析和读者回应的层次，以及按阅读障碍选策略；学生的联想与题目所需的文本证据仍分开。
- [小智伴学·写作教练](https://github.com/qizhitang/xiaozhi-skills/tree/main/student/chinese/xiaozhi-chinese-writing-coach)：借鉴分阶段写作、文体化反馈与聚焦一两处修改；学生明确要示范时仍提供原创示范。
- [小智伴学·教师端写作指导](https://github.com/qizhitang/xiaozhi-skills/tree/main/teacher/chinese/xiaozhi-teach-chinese-writing-guide)：借鉴用结构、语言、思考深度诊断作文；其等级换算不作为本地正式评分细则。
- [小智伴学·古诗文](https://github.com/qizhitang/xiaozhi-skills/tree/main/student/chinese/xiaozhi-chinese-classical-revival)：借鉴语境中的词义、诵读与理解衔接；角色扮演必须标记想象部分。
- [小智伴学·教师端文言指导](https://github.com/qizhitang/xiaozhi-skills/tree/main/teacher/chinese/xiaozhi-teach-chinese-classical-guide)：借鉴字形、组词与已学用法作为词义候选；以本句语境和当前教材最终核对。
- [Hermes 初中语文现代文阅读](https://github.com/hezkvectory/hermes-edu-skills/tree/main/skills/reading-writing/junior-chinese-modern-reading)、[教材同步](https://github.com/hezkvectory/hermes-edu-skills/tree/main/skills/textbook-sync/junior-chinese-tongbian-textbook-sync)、[短练](https://github.com/hezkvectory/hermes-edu-skills/tree/main/skills/daily-practice/junior-chinese-quick-practice)：借鉴从教材目标到练习、反馈和复测的闭环；不依赖其平台专有工作流工具。

## 加入新 reference 的门槛

新增方法卡时写清：适用题目、具体操作、一个可核对的例子、常见误用、来源编号、版本或地区限制、答案该怎样写。官方资料只说明课程方向时，直写“教学设计示例，待真实题目校准”；没有原文或有效来源的口诀不进入方法卡。真实错题先去掉姓名、学校等个人信息；只有用户明确要求保存时才写入长期资料。
