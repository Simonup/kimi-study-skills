# 现代文阅读：先读懂，再组织答案

## 使用范围

适用于记叙、散文、小说、说明、议论、新闻以及图表与多材料阅读。先读题目限定和全文，再选对应方法；文体只提供阅读视角，不直接决定答案。没有全文时，标明判断所依赖的段落范围。

来源定位：课程与教材目标参照 [S1、S2、S4](sources.md)；下面的答句顺序和原创例题是教学设计，须以当前题干、全文及老师批注 S0 校准，不是官方采分公式。

## 共同路线

`题目要我做什么 → 定位文本 → 用自己的话说明文本写了什么 → 解释它为何支持判断 → 按题目要求写成答句`。

| 题目动作 | 学生应留下的证据 |
|---|---|
| 概括 | 人、事、变化或对象、特征，删去无关细节 |
| 分析人物 | 一处语言、动作或选择，以及它支持的性格判断 |
| 赏析词句 | 被分析的词句、具体写出的内容、在语境中的效果 |
| 分析作用 | 此处写了什么，它与前后哪处形成关系；无关系就不写“铺垫”“呼应” |
| 解释标题 | 文中反复出现的所指、意义变化、它与全文的联系 |
| 多材料整合 | 每则材料的来源、单位、时间和相同或相异的信息 |

## 答句方法卡

### 词句赏析

1. 先问“这句话具体写出了什么”，用原文中的对象和动作回答。
2. 如题目要求写法或表达效果，再判断词语选择、句式、修辞或描写角度；说清这个写法改变了读者对什么的感受。
3. 情感判断要回到上下文；不能只凭“比喻”推断为“喜爱”，也不能把所有画面都答成“生动形象”。
4. 答句顺序：`具体写法或关键词 → 描写的具体内容 → 与上下文相连的效果或情感`。题目只问词义时，不额外堆三层。

### 人物形象

先找人物做的选择或说的话，再概括特点。一个特点对应一处能支撑它的证据；同一行为存在多种解释时，联系前后情节筛选。答句可写“从……可以看出……，因为……”。

### 段落或环境的作用

把段落前后各读一遍，画出真实联系：`此处的信息 → 后文事件/人物变化`。只在后文确有对应时写“铺垫”“伏笔”；只在文本确有重复与照应时写“呼应”。环境描写可提供时间地点、塑造氛围或呈现人物感受，按本段证据选择，不逐项罗列。

### 说明与议论

说明文先抓说明对象、特征、限制词和信息之间的次序；“大约”“可能”等词要结合语境说明其限制作用。议论文先找作者主张，再写所用材料如何支持该主张；引用名人或举例本身并不能自动证明论点。答句先讲具体论证内容，再讲作用。

### 非连续性文本

先读标题、图例、横纵轴、单位、时间和对象，再跨材料找共同点或冲突点。图表只显示相关或趋势时，不写成已证明因果。答句为每个要点标清材料出处；材料之间口径不同则先说明差异。

## 一轮微练与纠错

原创练习：“小雨把伞往同学那边挪了挪，自己的肩膀却湿透了。”问：从动作看出她什么特点？

- 先圈“把伞往同学那边挪”和“自己湿透”；前者是行为，后者是代价。
- 可写：“她把伞让给同学，自己淋湿，表现出对同学的关心。”
- 只写“她善良”缺少依据；写“她从小就是善良的人”则超出材料。

如果学生答错，先指出其答案中有根据的一部分，再修复第一处缺证据或跨得过远的判断。复测时更换动作、保留“行为 → 代价 → 品质”的结构。

## 六张方法卡与误答示范

### 1. 词句赏析：写法不能脱离具体内容

**适用：**题目指定一个词或一句话，问“有什么表达效果”。**原创示例：**“小林把皱巴巴的借书卡在裤腿上抹平，才推开图书馆的门。”题目问“抹平”一词的作用。

| 环节 | 本题可核对的内容 |
|---|---|
| 原句动作 | 小林把借书卡抹平，之后才进门 |
| 读者所得 | 这个停顿表现她在进门前认真整理借书卡 |
| 误答 | “生动形象地表现她十分喜悦”——文本没有写喜悦 |
| 可提交答句 | “‘抹平’写出小林进门前认真整理借书卡的动作，表现她对这件事的在意。” |

**方法：**圈具体动作 → 解释动作呈现的人物状态 → 回上下文检验情感。只有题目或文本确实需要时才加“动作描写”术语。**边界：**本句不足以证明她长期爱读书或此刻快乐。来源：S1 的阅读与鉴赏目标；例句与答案为原创教学示范，待 S0 校准。

### 2. 段落作用：证明前后确有联系

**适用：**题目问开头或结尾“有什么作用”。**原创示例：**开头“爷爷每天把一把旧钥匙放在窗台上。”结尾“搬家那天，我才知道，那是他给远方的儿子留的门钥匙。”

**误答：**“渲染气氛，升华主题。”这两个词没有指出钥匙与后文的关系。**可提交答句：**“开头写爷爷反复放钥匙，先留下‘钥匙给谁’的疑问；结尾揭示它是给儿子留的，回答了开头的疑问，也使爷爷的牵挂有了具体寄托。”

**方法：**定位被问段落 → 指出它写了什么 → 找后文对应处 → 说清两处如何改变读者的理解。后文若无对应，不写“伏笔”“呼应”。来源：S1、S2 的文本阅读方向；例句与答句为原创教学示范。

### 3. 非连续性文本：跨材料整合不等于补造因果

**适用：**题目给图表、公告或多则材料，要求比较、解释或提出判断。**以下均为原创模拟材料，数字不代表真实学校。**材料 A：某校图书馆借阅量，2024 年 1200 册，2025 年 1500 册。材料 B：图书馆在 2025 年开始周末开放。题目：能否据此认定“周末开放导致借阅量增加”？

**误答：**“能，因为借阅量增加了 300 册。”**可提交答句：**“不能直接认定。两则材料显示周末开放与借阅量增加发生在同一年，但未排除新增图书、学生人数变化等其他原因；能确认的是借阅量增加了 300 册。”

**方法：**分别记录每则材料的对象、时间与单位 → 找相同和不同 → 把材料直接显示的事实与推断分开 → 回答题目要求。**边界：**若题目补充了控制其他条件的证据，再重新判断。来源：S1 的信息阅读范围、S4 的综合实践方向；具体数字与题目为原创教学示范。

### 4. 概括：留下事件的变化，不照抄细枝末节

**适用：**题目问“用一句话概括主要事件”。**原创示例：**“小周发现走廊的饮水机漏水，先在水箱下放了盆，又向总务处报告。维修人员当天下午更换了水管。”

**误答：**“下午换了水管。”漏了问题由谁发现、怎样处理。**可提交答句：**“小周发现饮水机漏水并报告后，维修人员更换水管解决了问题。”**方法：**按“谁遇到什么问题 → 做了什么 → 结果如何”筛选；若题目只要结果，就不强写完整过程。来源：S1 的阅读理解目标；例句与答句为原创教学示范。

### 5. 说明：限定词改变事实范围

**适用：**题目问说明文中一个词能否删去。**原创示例：**“这张自习室预约单仅在当天有效，过期需重新登记。”问“仅”能否删去。

**误答：**“不能，因为‘仅’让语言生动形象。”**可提交答句：**“不能。‘仅’把有效期限定为当天；删去后，读者无法从这句话确定预约单是否只限当天使用。”**方法：**先说明原词限定了什么，再比较删去后信息如何变化；不机械写“体现说明文准确性”而漏掉具体范围。来源：S1 的语言理解目标；句子与答案为原创教学示范。

### 6. 议论：例子怎样支持观点

**适用：**题目问某事例的论证作用。**原创示例：**“整理读书笔记时，提出问题能帮助读者继续阅读。小夏读完一章写下‘主人公为什么改变决定’，第二天带着问题重读前文，找到了两处线索。”

**误答：**“举例论证，使文章生动形象。”**可提交答句：**“小夏带着自己提出的问题重读并找到了线索，这个事例具体展示了提问如何引导继续阅读，支持了前一句观点。”**方法：**先找论点，再指出事例中与论点相连的动作或结果，最后说明两者的关系。**边界：**单个例子是作者用来支持观点的材料，不自动证明所有读者都会得到相同效果。来源：S1 的思维与阅读方向；例文与答句为原创教学示范。
