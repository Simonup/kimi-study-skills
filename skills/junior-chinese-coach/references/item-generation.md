# 原创语文练习：先验题，再让学生作答

## 适用与来源

学生要求短练、同类追练或老师想要一题小测时使用。公开基础性作业的单元目标与实践方向见 [S5](sources.md)；这里的原创题是教学练习，不冒充正式考试题或地方评分标准。缺课文授权或原文时，以标明“原创模拟材料”的短文出题，不能伪称课后原题。

## 出题顺序

1. 写出**一个**训练目标，例如“从人物动作找到依据”或“比较两则材料的时间与对象”；对应本轮学生确有的卡点，或用户指定的目标。
2. 选用户提供且可辨认的文本，或写一段原创短材料。把题目用到的事实全部放进材料。
3. 先自己独立解答，再写题干。题干说明答题动作、材料范围与限定；开放题允许不同但有证据的表达。
4. 选择题逐项核查：正确项由材料充分支持；每个干扰项有能指出的错误原因；若两个选项都成立，改题干或改成开放题。
5. 写参考答句和依据位置，再写一种常见误答为何错。没有可核对的依据就撤回该题重做。
6. 向学生先显示材料和题目。学生作答后再显示参考答句、证据与下一步；学生主动要答案时立即给。

## 交付前的七项检查

| 检查 | 不通过时的动作 |
|---|---|
| 目标只有一项 | 删去多余的小问 |
| 材料完整清楚 | 补足限制或撤掉依赖外部知识的问法 |
| 答案可从材料推出 | 重写答案或题目，禁止补造背景 |
| 开放题容纳有据异答 | 给出判断条件，不设唯一措辞 |
| 选择题只有一个最佳项 | 修正干扰项；仍有争议就改开放题 |
| 难度符合已提供的年级与当前目标 | 缩短材料或补前置提示 |
| 题目、答案、解析彼此一致 | 停止交付，逐句重读材料与解释 |

## 完整原创示范

**目标：**提取一则流程材料的信息。**原创模拟材料：**“校广播站周三收稿，周四核对稿件中的日期、人名和引文出处，周五午间播出。”

**题目：**根据材料，周四最主要的工作是什么？A. 核对稿件事实与出处　B. 收集稿件　C. 午间播报　D. 采访作者。

**答案与依据：**A；材料明说“周四核对稿件中的日期、人名和引文出处”。B 对应周三，C 对应周五，D 未在材料中出现。四项均已逐项核对，只有 A 与所问日期相符。学生答 B 时，先让她圈“周四”，再核对材料的时间顺序；下次把日期换成“播报之前一天”做同结构复测。

## 开放题的边界

“你如何理解人物的选择”这类题不能只凭本文件的单一示范宣称唯一答案。交付时列出必须回应的题干限制和文本证据，再容纳用不同词语表达的合理判断；老师给出该题具体批注时据此校准。
