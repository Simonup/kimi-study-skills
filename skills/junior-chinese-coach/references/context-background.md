# 作品背景：补一把钥匙，回到原文开门

来源定位：作品、课题、注释以学生当前材料 S0 为准；《春望》诗句见 [S7](sources.md)，杜甫战乱时期的处境见 [S8](sources.md)；《背影》原文见 [S9](sources.md)。背景筛选的教研依据见 [S10](sources.md)。以下讲法是本 skill 的教学设计，不是官方标准答案。

## 何时补背景

学生问“写作背景、时代、作者经历、典故、为什么这样写”，或某句只看字面难以理解时，启动背景讲解。先读题目和关键原句，再判断缺的是哪类信息：

| 当前卡点 | 先查的背景 |
|---|---|
| 不明白地名、官职、制度、典故 | 注释、时代中的词义与文化用法 |
| 不明白人物为何这样做 | 文内处境与事件先后；必要时查外部史实 |
| 不明白景物为何带有情绪 | 全篇语气、写作处境、诗题与相关原句 |
| 不明白文章为何这样组织 | 文体、叙述视角、写作或发表信息 |

背景只选能解释当前词句或篇章的一至两项。学生明确要系统了解时，再扩展作者与时代小时间线；每个时间点都标出它连接的原句。作者生平、写作年代、文学流派不能替代对作品的阅读。

## 查证与讲解的四步

1. **先定文本版本。** 读取本轮课本的标题、作者、注释、序跋及关键段落。教材选文若有删节、改题或异文，写明所依据的版本；没有课本页时，标记为待校准。
2. **分清三层信息。** `A 文本直接写出`、`B 外部资料核实`、`C 据文本和背景作出的解释`。给 B 层保留可查的书名、页码或网页链接；C 层使用“有助于理解”“可解释为”，不用确定史实的语气。对写作年份、地点、典故出处、作者意图有争议时，列出不同说法及出处；核不到就略去具体断言。
3. **把背景接回原句。** 按`背景事实 → 原文中的词句 → 这一信息改变了什么理解`讲述。先用两三句话讲清必要处境，再让学生重读该句。背景是解释的线索，答阅读题仍须引用或转述题给文本。
4. **检查越界。** 区分真实作者、叙述者、抒情主人公与作品人物；不能把人物所想直接说成作者所想，也不能因为作者经历过某事就判定每句都在写此事。区分“作品所写时间”与“写成、发表时间”。

## 两个可核对的示范

**古诗词：《春望》。** 文本写“国破山河在，城春草木深”“烽火连三月，家书抵万金”（S7）。外部史料说明杜甫在安史之乱中曾困于被叛军占据的长安（S8）。把两者连起来：“城春”本可让人想到生机；放在“国破”和战争处境里，“草木深”更显都城荒凉；“烽火”与“家书”又把国难和牵挂家人连在一起。这是依据文本与史实作出的解释，不必给未核对的精确写作日期。若题目只问首联景象，答句集中写景象，不把整段史实搬入试卷。

**现代课文：《背影》。** 原文开头直接交代祖母去世、父亲失业、家中光景惨淡（S9）：这是**文内背景**，不需先搜索作者年谱。再读车站买橘子的动作，就能看出送别发生在家庭困顿中，父亲仍要亲自照料儿子。可用`家中处境 → 车站行动 → 我的反应`做一条短时间线。不能仅凭这篇课文推定朱自清写作当天的心情或文章发表年份；要讲这些外部事实须另查可靠出处。

## 面向学生的输出

默认给一张不超过两列、三行的“背景—原句”表，或用三句话：`当时发生了什么〔来源〕 → 文中哪里看得出 → 因而这句话多了一层什么意味`。学生要深入了解时，补充一条小时间线、一个文化词条和“哪些仍不确定”，但每项都回扣原文。末尾用白话追问：“知道这件事后，你对哪一个词的理解变了？”有题目时照主 skill 写“这题怎么想／这类题怎么写”。
