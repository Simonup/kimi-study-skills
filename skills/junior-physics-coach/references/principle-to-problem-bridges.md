# 从基础原理走到考题

本文件供教练按需检索。目标是让学生在题目中认出课堂规律的**适用条件**，并知道条件改变时哪一步要变。讲一题时只选最关键的一条桥，不朗读全部卡片。若学生深化追问时还没有直观画面，先用 [感性场景与深化追问](sensory-anchors-for-followups.md) 中的前后对比，再走下方的抽象桥接。

## 双向桥接：先从课本走向题目，再从题目走回原理

**正向：**看到的现象 → 哪些对象怎样相互作用／哪个量怎样变化 → 在什么条件下形成规律 → 考题怎样用文字、图或数据给出这些条件 → 第一步该画什么或列什么。

**反向：**圈出题目原句或图上的标记 → 翻译成物理状态 → 核对规律的前提 → 说明为什么能走这一步 → 改动一个条件，指出原解法哪里失效。

一个可直接说给学生听的短句：

> 课上讲的____，在这道题里不是单独出现的。题目中的“____”表示____，这正好满足____规律的____前提，所以第一步____。如果把“____”改成“____”，刚才的____就不能直接写。

只凭关键词匹配无法完成这座桥。例如见到“水”不一定用浮力，见到“运动”不一定合力不为零，见到“灯泡”不一定能用恒定电阻。

## 先诊断断在哪一段

| 学生的表现 | 缺的是哪座桥 | 本轮动作 |
|---|---|---|
| 能背定义，讲不出为何发生 | 现象 → 机制 | 画前后两帧，写清对象、相互作用与变化量 |
| 会讲原理，看不出题目为何用它 | 题目证据 → 规律前提 | 圈题目原句或图示，译成物理状态，再核对前提 |
| 会选公式，列式常错 | 模型 → 数量关系 | 写清每个符号指什么，核对对象、方向、单位与限制 |
| 会做原题，换问法就不会 | 规律 → 条件迁移 | 只改一个条件，比较原式中哪一项要变 |

学生没有说自己卡在哪段时，先用本题要求她指出“题目哪句话允许你用这条规律”；若答不出，从证据与前提的桥开始讲。完整解答时直接展示对应关系，不靠连续追问拖延。

## 桥接卡 1：匀速运动与受力平衡

**课堂现象与机制：**水平推箱子时，推力与摩擦力可以同时存在。箱子做匀速直线运动，速度的大小和方向都不变；在初中模型中，它所受合力为零。

**考题证据：**“箱子在水平地面上沿直线匀速前进”；题目还需说明或能判断水平方向只有推力和摩擦力。

**转成解题动作：**先画箱子受力图，在水平方向列 `F推=f`。这个等号来自合力为零及水平方向只有这两个力，并不来自“箱子正在动”。

**改一个条件：**若题目改成“速度逐渐增大”，原来的平衡前提消失，不能直接写 `F推=f`。若增加另一水平方向外力，即使仍匀速，也要把该力计入平衡。

**可问的检验句：**“这道题的哪个词，让我们有资格把两个力写成相等？”

## 桥接卡 2：压强从海绵实验走到计算题

**课堂现象与机制：**同样大小的垂直压力落在更小的实际受力面积上，单位面积承担的力更大，海绵在该实验中下陷更深。压强定义为单位面积所受的垂直压力：`p=F/S`。

**考题证据：**“同一物体分别用大面和小面水平静放”，且两次只有重力与支持力参与竖直平衡；或题目直接说明“压力相同”。先确认实际接触面积是哪一面。

**转成解题动作：**说明两次压力大小相同，再比较 `S`：面积越小，`p` 越大。若求数值，先由已知条件确定 `F`，再代入实际接触面积。

**改一个条件：**若有人从上方额外按压小面，两次压力未必相同，不能只比较面积。海绵下陷是观察指标，不能把下陷深度直接写成压强数值。

**可问的检验句：**“实验里固定了什么量？考题里哪句话保证它仍固定？”

## 桥接卡 3：浮力把“排开水”与“漂浮平衡”分开

**课堂现象与机制：**液体对浸入物体的作用可合成为向上的浮力；在阿基米德原理适用的条件下，浮力等于被排开液体的重力，`F浮=ρ液gV排`。

**考题证据 A：**题目给液体密度和物体排开液体的体积，或给出足以求 `V排` 的条件。此时先找排开体积，再求浮力。

**考题证据 B：**题目说“物体在液面上静止漂浮”，且竖直方向只有重力和浮力。此时由平衡可直接写 `F浮=G物`，不必先求 `V排`。

**改一个条件：**改成“物体沉底静止”，底部可能还给支持力，不能沿用 `F浮=G物`；改成“完全浸没后继续下沉”，若液体密度和排开体积不变，不能只凭“更深”断言浮力更大。

**可问的检验句：**“你用的是‘排开液体’这条路，还是‘静止平衡’这条路？题目给了哪种证据？”

## 桥接卡 4：电路从“路径”走到电流、电压关系

**课堂现象与机制：**电流要沿闭合回路通过。理想串联电路只有一条路径，各串联元件中电流相同；在分支电路中须先辨认每条支路，不能沿用一条路径的结论。

**考题证据：**看导线连接的节点、开关当前状态以及从电源一端到另一端的路径数，不凭元件在纸上的排列位置判串并联。

**转成解题动作：**标节点 → 追完整路径 → 判连接 → 标电表测量对象 → 写该连接方式下的电流、电压关系；只有元件可视为恒定电阻且给出相应条件时才再用欧姆关系。

**改一个条件：**开关状态变化后先重画有效路径。若原来串联的两元件因开关变化形成分支，原先“处处电流相同”的使用范围也改变。

**可问的检验句：**“在写公式前，能从电源一端到另一端数出几条有效路径吗？”

## 桥接卡 5：实验题把“观察”接到“有范围的结论”

**课堂现象与机制：**探究一个因素的作用时，要辨认主动改变的量、测得的量和保持相同的条件。观察现象本身不等于已证明普遍规律。

**考题证据：**实验组与对照组、仪表读数、表格中的变化，以及题目明确控制的条件。先圈出“只改变了什么”。

**转成解题动作：**按“问题 → 自变量 → 因变量 → 控制条件 → 两组证据 → 限定范围的结论”书写。若只给单组数据或有其他因素同时改变，明确说证据不足以单独归因。

**改一个条件：**若两组同时更换物体材料和受力面积，不能把结果全归因于面积变化；需补对照或缩小结论。

**可问的检验句：**“你写的结论，能在表格里指出支持它的两组证据吗？”

## 桥接卡 6：声音从琴弦现象走到波形图

**课堂现象与机制：**声源振动引起周围介质的扰动；音调主要取决于振动频率，响度还受振幅及传播条件影响。

**考题证据：**两段波形使用相同的时间刻度；在同样长的时间窗内，一段完成更多次振动，表示频率更高。图上峰更高表示振幅更大，不能直接读成频率更高。

**转成解题动作：**先读横轴时间和纵轴振动量，再分别数相同时间里的振动次数、比较振幅；答“音调”用频率证据，答“响度”先核对传播与观察条件。

**改一个条件：**若两图横轴每格代表的时间不同，不能直接数图上波峰个数来比较频率；先换到相同时间长度。

**可问的检验句：**“你比较的是相同时间内振动了几次，还是图上峰画得多高？”

## 桥接卡 7：熔化现象走到温度—时间图

**课堂现象与机制：**在题目给定的纯净晶体和压强条件下，熔化过程中吸收的能量主要用于改变物态，固液共存阶段温度可保持在熔点附近。

**考题证据：**题目说明持续加热，温度—时间图有一段近似水平的平台，并给出或可判断该物质在熔化。

**转成解题动作：**先读横纵轴及加热条件，再指出平台内温度近似不变、物质仍在吸热、状态可能是固液共存。平台温度不是“停止吸热”的证据。

**改一个条件：**若题目换成混合物或改变压强，不把原平台温度无条件当作该物质的新熔点；回到题目图像和材料条件判断。

**可问的检验句：**“图线水平告诉我们哪个量不变？题目又用哪句话告诉我们能量仍在输入？”

## 桥接卡 8：平面镜原理走到成像作图

**课堂现象与机制：**物体发出或反射的光到达镜面，再反射进入眼睛；眼睛把光线反向延长，感觉光来自镜后。镜后没有真实光线会聚，所见位置是虚像。

**考题证据：**题目给平面镜、物点与观察者位置，或要求画像的位置与光路。先分清实线的真实光线和镜后虚线的反向延长线。

**转成解题动作：**先画镜面及物点，再按题图给出的垂直距离确定像点；需要光路时从物点到镜面、再到眼睛画真实传播方向，镜后的反向延长线用虚线。

**改一个条件：**若题目改为“把屏幕放在镜后承接像”，不能因为眼睛看得见像就断定屏幕能接到它；镜后没有真实光线到达并会聚。

**可问的检验句：**“你画在镜后面的线，是真实光走过的路，还是眼睛反向追踪得到的虚线？”

## 原理讲解后的最小迁移练习

讲完一个原理，给一道只含一个判断的小题，不先要求整套计算。示例：“一个箱子沿直线匀速运动，水平方向只有推力和摩擦力。题目哪一句保证可以写 `F推=f`？”学生答出“沿直线匀速”后，再改为“加速运动”，请她指出等号失效的原因。若学生仍无法连上，退回对象图或前后状态图，再做同一题；不另开一整章讲义。
