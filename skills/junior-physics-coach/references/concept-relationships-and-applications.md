# 初中物理概念：说清关系，再用到题里

本文件供教练按当前卡点检索。不要把整张概念图交给学生背；一次只讲与本题直接相连的两个或三个概念。先读学生的课本、题图与已写步骤，再选下面一张关系卡。学生开始追问“为什么”或感到生活经验与答案冲突时，先按 [感性场景与深化追问](sensory-anchors-for-followups.md) 展示可观察的前后变化，再使用本文件中的概念关系。

## 一次概念讲解走五步

1. **看见：**用学生熟悉的一个场景描述能观察到什么，指出研究对象。
2. **说清：**用一句白话解释一个新概念，再补教材常用术语；先不用公式压住解释。
3. **连起来：**说明它与相邻概念是“相同／不同”“一个量由另两个量决定”“一个条件允许某规律使用”中的哪种关系。画一条箭头或两列表，写清箭头为何成立。
4. **放进题里：**引用题目原句、图示或数据，指出它对应哪个概念与前提，然后完成第一步判断或列式。
5. **换条件：**只改一个条件，让学生判断原关系是否仍能用；要求完整解答时直接给出判断及理由，明确要求提示时只提一个问题。

白话解释必须能回答“它是说哪个物体、哪段过程或哪两个点”。若比喻会让学生把两种量混成一种量，撤回比喻，改用物体图、路径图或有单位的两列表。使用 `🟨 **关键一句：……**` 标出本轮核心结论；其余加粗只突出会改变解法的条件。

## 关系卡 1：路程、时间、平均速度

**白话：**路程是这段过程实际走了多长，时间是这段过程花了多久，平均速度是“每单位时间平均走了多长”。

`同一段过程的总路程 s + 总时间 t → 平均速度 v=s/t`

**关系与区别：**分子和分母必须来自**同一段过程**。全程平均速度用全程总路程除以全程总时间；它不代表途中每一刻都同速。停下来的时间是否计入，看题目如何界定“全程”。

**题目里怎么用：**见到“两段路程、两段时间，求全程平均速度”，先分别合并总路程和总时间，再相除；不能直接平均两段速度。

**换一个条件：**若某段增加停车等待，路程不变而全程时间增加，全程平均速度会减小。[机制卡](phenomena-motion-sound-heat-optics.md)

## 关系卡 2：质量、体积、密度与重力

**白话：**质量描述物体所含物质的多少；体积描述它占多大空间；密度描述在给定状态下，均匀材料的单位体积有多少质量。重力是地球对物体的吸引作用，单位是牛顿，与质量不是同一个量。

`同种均匀材料、状态不变：体积变大 → 质量按比例变大；ρ=m/V 保持相同`

`同一地点：质量 m → 重力大小 G=mg`，但质量用千克，重力用牛顿。

**关系与区别：**把一块均匀材料切成两半，每一半的质量和体积都变小，密度通常不因此改变。空心、混合材料或温度变化时，先检查能否按同一种均匀材料处理。

**题目里怎么用：**给质量和体积、问材料密度，用 `ρ=m/V`；给质量、问重力，用题设 `g` 计算 `G=mg`。先看所求量及单位，不能见到 `m` 就任选公式。

**换一个条件：**若物体中间挖空，整件物体的平均密度与材料密度要分开。[机制卡](phenomena-motion-sound-heat-optics.md)

## 关系卡 3：力、运动状态与受力平衡

**白话：**力是物体之间的作用。物体可以一边运动，一边受几个力；要判断运动状态会不会改变，要看这些力合起来的作用。

`静止或匀速直线运动 → 运动状态不变 → 合力为零`

**关系与区别：**“正在运动”不等于“合力不为零”。箱子匀速前进时，水平方向的推力和摩擦力可以大小相等、方向相反；还要核对是否有其他水平方向的力。

**题目里怎么用：**题目写“沿直线匀速”，先选物体并画受力图，再在同一方向上列平衡关系；不要单凭箭头画得长短判断力的大小。

**换一个条件：**改为速度增大或转弯，运动状态变了，不能直接沿用“合力为零”。[机制卡](phenomena-mechanics-energy.md)

## 关系卡 4：压力、受力面积与压强

**白话：**压力是物体垂直压在接触面上的力；压强表示这股压力分摊到每单位实际受力面积上有多大。

`压强 p = 垂直压力 F ÷ 实际受力面积 S`

**关系与区别：**压力变大或受力面积变小，都可能让压强变大；比较时必须交代另一个量是否保持相同。压力不总等于物体重力，受力面积也不是整个物体表面积。

**题目里怎么用：**“同一物体分别用大面和小面水平静放”提供相同重力及可核对的平衡条件；先确认两次压力相同，再比较实际接触面积。若求数值，先求压力大小，再代入面积。

**换一个条件：**若有人额外向下按，压力可能改变，不能只看面积。[机制卡](phenomena-mechanics-energy.md)

## 关系卡 5：浮力、排开体积与漂浮平衡

**白话：**浸入液体的物体会受到液体向上的浮力；物体排开的液体越多，在同一种液体中浮力通常越大。

`液体密度 ρ液 + 排开体积 V排 → F浮=ρ液gV排`

`静止漂浮，竖直方向只有浮力和重力 → F浮=G物`

**关系与区别：**第一条看排开液体，第二条看物体是否平衡；两条关系来自不同的依据。物体完全浸没后，在液体密度近似不变且排开体积不变时，继续下沉不会只因“更深”就使阿基米德浮力增大。

**题目里怎么用：**给 `V排` 和液体密度，走排液路线；给“静止漂浮”和质量，先核对受力再走平衡路线。

**换一个条件：**改为沉底，底部可能提供支持力，不能直接写 `F浮=G物`。[机制卡](phenomena-mechanics-energy.md)

## 关系卡 6：温度、热量与物体的内能

**白话：**温度告诉我们物体冷热程度；内能是物体内部微粒运动和相互作用对应的能量；热量指热传递过程中转移了多少能量，不是物体“装着”的一种东西。

`有温度差且发生热传递 → 能量从较热物体传向较冷物体`

**关系与区别：**物体吸收热量，内能可能增加；温度**不一定立刻升高**。题目中的纯净晶体熔化平台就是常见例子：持续吸热，能量用于物态变化，温度近似不变。

**题目里怎么用：**读温度—时间图时，先看横轴时间、纵轴温度，再看题目是否持续加热；若有熔化平台，分别回答“是否吸热”和“温度是否变化”，不能用一个答案代替另一个。

**换一个条件：**若停止加热且没有其他热量输入，就不能凭“图线水平”断言仍在吸热。[机制卡](phenomena-motion-sound-heat-optics.md)

## 关系卡 7：电压、电流与电阻

**白话：**电流是电荷有方向地移动形成的；电压可以先理解为电路两点之间的电学差别，是形成持续电流的条件之一；电阻描述导体对电流的阻碍。三个量是不同的，不能只用“水流大小”解释全部。

`先看闭合路径与测量位置 → 找两点间的 U、该支路的 I、该元件的 R`

**关系与区别：**在题目允许把同一元件的电阻看作恒定时，该元件两端 `U` 越大，经过它的 `I` 越大，可用 `I=U/R`。这个关系须先确认**同一元件、同一工作条件**；灯泡温度改变时不默认电阻恒定。

**题目里怎么用：**先沿导线找闭合路径，标电压表跨接的两点和电流表所在支路，再确定已知电压是否就是所求元件两端的电压；最后才列式。

**换一个条件：**开关改变连接，先重画路径；不能沿用之前的串并联关系。[机制卡](phenomena-electricity.md)

## 关系卡 8：功、功率与机械效率

**白话：**功描述力使物体沿力的方向移动时所做的事；功率描述做功快慢；机械效率比较有用功占总输入功的多少。

`力 F 与沿力方向的位移 s → 功 W=Fs`（本式用于力与位移同向且力大小可按题目视为不变的情境）

`同一段过程的功 W 与用时 t → 功率 P=W/t`

`有用功 W有用 与总功 W总 → 效率 η=W有用/W总`

**关系与区别：**做功多，不一定功率大，还要看用时；省力的机械不等于省功，还要看施力点移动的距离。效率不能超过 100%。

**题目里怎么用：**问“做了多少功”先找力与位移；问“做功有多快”再找时间；问“输入中多少用于目标”先分清有用功和总功。

**换一个条件：**重物静止不动时，支持它的力没有使它沿力方向移动，不能直接用该力乘时间算功。[机制卡](phenomena-mechanics-energy.md)

## 关系卡 9：音调、响度与波形

**白话：**音调说声音听起来高还是低；响度说声音听起来大还是小。声源振动越快，频率越高，音调通常越高；声源振幅增大常使声音更响，但听到的响度还受距离和传播条件影响。

`同样长的时间里振动次数 → 频率 → 音调高低`

`振动幅度 + 传播与接收条件 → 听到的响度`

**关系与区别：**波形上“挤得密”与“峰画得高”不是一回事。先确认两图的横轴时间刻度相同，再比较振动次数；不能把更高的峰直接叫作更高的音调。

**题目里怎么用：**问音调，看同一时间内振动次数；问响度，核对振幅及其他条件。读题目给出的波形图时先写横轴和纵轴各表示什么。

**换一个条件：**两张图的时间刻度不同，不能只数纸面上的波峰多少。[机制卡](phenomena-motion-sound-heat-optics.md)

## 关系卡 10：真实光线、反向延长线与虚像

**白话：**镜子把光反射到眼睛，眼睛会觉得光来自镜后。镜后那个位置能“看见”像，但那里没有真实光线会聚，所以叫虚像。

`物体来的光 → 镜面反射 → 眼睛；眼睛沿来光方向反向追踪 → 镜后虚像位置`

**关系与区别：**真实传播的光线画实线；为找像而向镜后画的反向延长线画虚线。“虚像”不是看不见，而是不能把屏幕放在镜后直接承接真实光线形成的像。

**题目里怎么用：**要求平面镜作图时，先画镜面、物点和实际反射光路，再用虚线定位像；比较物距、像距时量的是到镜面的垂直距离。

**换一个条件：**把题目改为“能否在屏幕上承接”，先问有没有真实光线在屏幕处会聚。[机制卡](phenomena-motion-sound-heat-optics.md)

## 给学生看的示范答法：压力与压强

一本书平放和立放在同一块海绵上。书没换，海绵上的接触面却变了。

**压力**是书压在海绵上的力。

**压强**看这股力分摊在多大面积上。

| 看什么 | 这道题里的意思 |
|---|---|
| 压力 | 同一本书水平静放，两次大小相同 |
| 受力面积 | 立放时接触面积更小 |
| 压强 | 同样的压力集中在更小面积上，所以更大 |

🟨 **关键一句：压力相同，实际受力面积越小，压强越大。**

题目如果改成“有人用手向下按书”，压力也可能变。此时先核对两次压力，不能直接沿用刚才的比较。
