# 感性桥接：首轮给支点，追问时补机制

首轮解题遇到直觉冲突或常见概念误接时，用对应卡片的一组可感对比和“回原题”两段；学生追问“为什么／凭什么／如果……会怎样”、指出生活经验与答案冲突，或听过一次概念解释仍说不懂时，再沿机制补一层。先回答当前问题，一轮只追溯当前推理缺少的一层背景，不把场景串成整章讲义。生活画面负责让学生发现变化，原题条件负责证明结论；两者须分开说。

## 讲后怎样检查孩子自己会不会用

完整解答和解题方法照常给完；当本题的关键原理易混淆时，在末尾留一道独立检查题，换一个对象、图示或决定规律适用的一项条件。只问“结论是什么？新题哪条条件支持它？”不预先给检查题答案，不用原题只换数字。若学生只要本题答案或表示不想练习，停在完整解答。讲解中为说明规律而给出的示范变式则当场给答案，不能把示范与独立检查混为一谈。

收到学生回答后，分开看三件事：**结论、证据、条件怎样产生结论**。只答对选项或只写公式，仍要补“题里哪句话允许你这么用”；答错时指出第一处断裂，改用更小的可感对比，让她重新判断一题。学生没有作答，不记录为会；答对一次也只说明这道迁移题走通。

## 感性桥接的六个动作

1. **答当前问题：**用一句话说出结论，不用连续反问延迟答案。
2. **给可感场景：**优先选学生熟悉的真实经历；没有共同经历时，换安全桌面演示或准确的两至三帧过程图。说明她能看见、听见或感觉到的具体变化，不先报定律名称。
3. **比两个状态：**保持对象相同，只改变一个条件；说清哪个现象出现、消失或变强。可以让学生先预测；要求完整解释时，紧接着给出预测与理由。
4. **找作用与机制：**指出谁作用于谁、哪一个量发生变化，解释场景中每一步。此时才引入“摩擦力／压强／浮力”等术语和适用条件。
5. **接回原题：**引用题目原句或图示，明确它相当于场景中的哪一帧；说明生活里多出的阻力、材料变化或测量误差，不能偷偷带进题目模型。
6. **改一条件：**讲解示范时只变动题目中的一个条件，直接说明原结论是否仍成立，以及要改的那一步。需要检验学生是否会用时，另给一道未泄露答案的独立检查题，等待她说结论与题目依据。

场景选择顺序：**确实熟悉的经历 → 安全、可重复的桌面观察 → 标清对象与方向的过程图 → 有明确失效处的比喻**。不能假定学生坐过某种车、摸过某种材料或做过某个实验；不熟悉就换场景。若场景本身有多个因素同时变化，点明只用它帮助看见哪一个关系，再回到题目条件核对。

## 卡 1：为什么匀速移动的 A 可以不受水平摩擦力？

**先答：**题目中的 A 随 B 做匀速直线运动，且不计空气阻力；A 水平方向若只有 B 给的摩擦力，它只能是 0。

**可感画面：**想象自己站在平稳行驶的车内：刚起步时身体相对车厢向后晃；车开稳的一段不会持续向后晃；刹车时身体相对车厢向前晃。若孩子没坐过车，改为把橡皮放在课本上，比较课本突然起动、平稳移动、突然停下时橡皮相对课本的表现。桌面演示只看变化趋势，不声称测出了 0 N。

**机制：**起步时，车的地板要通过脚底摩擦让人跟着加速；刹车时它又要让脚减速。平稳直行时，速度不再改变，在忽略空气阻力和颠簸的模型里，不需要持续的水平力维持已有速度。日常推箱子往往要一直推，是在抵消地面对箱子的阻力；这不等于每个正在运动的物体都受向前的力。

**回原题：**A 像车上的人，B 像车；“一起匀速直线运动”对应开稳的那一帧。A 不接触地面，题目又不计空气阻力，不能把 B、C 与地面的摩擦力算到 A 身上。对 A 而言，唯一可能的水平力是 B 的摩擦力；水平合力为 0，所以这一个力为 0。

**改一条件：**把“匀速”改为“B 带 A 向右加速”，A 要跟着加速时，B 对 A 的静摩擦力可能向右且不为 0；具体大小仍须题目给出足够条件。不能只因 A 与 B 接触，就断言一定有摩擦力。[受力机制](phenomena-mechanics-energy.md)

**给学生看的示范答法：**“A 受到的水平摩擦力是 0 N。想想车刚起步时人会向后晃，开稳了却不会一直晃；这个画面帮我们看见的是**速度改变与不改变的差别**，不能测出摩擦力是几牛。要判断 A 的力，仍须看题目：A 匀速直线运动，不接触地面，又不计空气阻力；它在水平方向只可能受到 B 给的摩擦力。水平合力为 0，所以这个力是 0 N。日常推箱子要一直推，是因为地面阻碍箱子；不能把那份阻力搬到 A 身上。”

**独立检查题：**另一个小木块放在沿水平直线运动的传送带上，题目说木块和传送带一起**向右加速**，且木块水平方向只可能受到传送带的摩擦力。摩擦力还能是 0 N 吗？是哪条新条件改变了原题的判断？学生答复前不公布结论。

## 卡 2：为什么面积变小，压强会变大？

**先答：**在压力大小相同的条件下，同一股压力落在更小接触面积上，单位面积承担的力更大。

**可见画面：**同一块橡皮或同一本书分别用大面、小面静放在同一块软海绵上，观察接触面和海绵下陷。先确认物体没有更换，也没有额外向下按；下陷只是压力作用效果的观察指标，不是压强读数。

**机制：**两次物体受到的重力相同；在水平静放且竖直方向只有重力和支持力时，物体压海绵的力大小相同。小面把同样的力集中在更小范围，海绵局部更容易变形。此时才写 `p=F/S`，说明 `F` 和 `S` 分别指什么。

**回原题：**圈出“同一物体／压力相同”和“大面、小面”的对应条件，再比较实际接触面积。若题目有人加力按压，先重新确定压力，不能只看面积。

**改一条件：**面积不变而压力增大，压强也增大；海绵材料换了，只凭下陷深度不能直接比较两次压强。[压强机制](phenomena-mechanics-energy.md)

## 卡 3：为什么漂在水上的物体会受到向上的力？

**先答：**物体进入水中后，水对它各处都有作用；这些作用合起来可形成向上的浮力。

**可感画面：**把乒乓球缓慢按入水中，手会感到它向上顶；按入得更多时，排开更多水，向上的作用通常增强。球全部浸没后，在液体密度近似不变的水中，继续加深而排开体积不变，阿基米德浮力不因深度本身增加。

**机制：**水越深压强越大；对浸入物体，上下等处液体压力合成向上的效果。计算时把这效果与排开的液体联系起来：`F浮=ρ液gV排`。若题目说“静止漂浮”，还要看物体的竖直受力，才能用 `F浮=G物`。

**回原题：**先分清题目给的是“排开水多少”还是“静止漂浮”，分别对应阿基米德关系或平衡关系。手按住球时，手的力也参与平衡；不能把按住的球直接当成自由漂浮。

**改一条件：**球改为沉底，容器底部还可能给支持力，不能直接写 `F浮=G物`。[浮力机制](phenomena-mechanics-energy.md)

## 卡 4：为什么冰在融化时吸热，温度却可以不升？

**先答：**在题目规定的纯净晶体熔化条件下，输入的能量主要用于改变物态，所以温度可在熔化阶段近似保持不变。

**可见画面：**看一小块冰逐渐化成水：形状和固液比例在变化。仅凭眼睛看不出精确温度，温度是否出现平台要靠题目给的温度计读数或温度—时间图，不凭想象补测量。

**机制：**周围向冰传递能量；微粒的排列和相互作用在改变，固态部分逐渐减少。若题图显示一段温度平台，应把“继续吸热”和“温度近似不变”作为两个不同判断。

**回原题：**圈出“持续加热”和图中的水平段，分别对应能量输入和温度读数；不能由图线水平推出停止吸热。

**改一条件：**若改成混合物或停止加热，不自动沿用原平台解释，先看材料与能量输入条件。[熔化机制](phenomena-motion-sound-heat-optics.md)

## 卡 5：为什么弹紧的弦声音更尖？

**先答：**在弦的长度、粗细等条件相同的比较中，弹得更紧常使它振动得更快，音调更高。

**可听画面：**轻拨同一根橡皮筋，比较拉得较松和较紧时的声音；让学生先说听起来“高低”变化，而不是“大小”变化。演示只用适度拉伸的橡皮筋，不朝人弹射。

**机制：**音调对应振动频率，即相同时间里振动了多少次；响度与振幅和传播条件有关。“声音更尖”先译为音调更高，再看频率，而不是看波形画得有多高。

**回原题：**若考题给两张波形图，先核对时间刻度，再数相同时间内的振动次数；不要把振幅大的图直接判为音调高。

**改一条件：**若两图时间刻度不同，先换到相同时间长度才能比较频率。[声音机制](phenomena-motion-sound-heat-optics.md)

## 卡 6：为什么溢出液体质量相同，金属块体积却不同？

**先答：**相同质量的水和酒精，水的密度更大，所占体积就更小；两块金属完全浸没时，各自排开的液体体积等于自身浸入液体的体积。

**可感画面：**想象两袋质量相同、颗粒疏密不同的填充物，一袋鼓些，一袋瘪些：秤上同样重，占的空间仍可不同。这个画面只帮助区分“质量”和“体积”；它不能替代水、酒精密度的题目数据。酒精只看题图，不要求未成年人动手操作。

**机制：**对溢出液体写 `m溢=ρ液V溢`。两边溢出质量相同，且 `ρ水>ρ酒精`，因此 `V溢水<V溢酒精`。容器起初装满且两块金属都完全浸没时，`V溢水=V_A`、`V溢酒精=V_B`，于是 `V_A<V_B`。比较金属密度还要分别用 `ρ_A=m_A/V_A`、`ρ_B=m_B/V_B`，不能仅凭质量大小判断。

**回原题：**画面提示“同质量未必同体积”；真正推出 `V_A<V_B` 的是“溢出质量相同”“水比酒精密”“两块完全浸没”“原先装满”四项题目条件。若原题问“有可能”，需检查某选项是否存在满足这组关系的取值，不能把可能误判为必然。

**独立检查题：**把两杯液体改为同一种液体，两块金属仍完全浸没，溢出液体质量仍相同。现在两块金属体积有什么关系？用哪两条条件判断？学生答复前不公布结论。

## 卡 7：为什么开关改变后，要重新数电流路径？

**先答：**开关断开或闭合，会改变电路中哪些路真正接通；原来只有一条路的判断不能直接沿用。

**可见画面：**先用纸上两幅简图画同一回路的开关断开和闭合，沿导线从电源一端描到另一端；断开的地方像路面缺了一段，笔迹接不上。手电筒开关可辅助感受亮与灭，但灯不亮还可能是电池、灯泡或接触问题，不能仅凭“不亮”断定开关断开。

**机制：**有电源且路径闭合，才存在持续电流；判断串联、并联时先看节点和闭合路径数，不凭元件在纸上的上下左右位置。若开关形成新的支路，原先只适用于一条路径的关系也要重查。

**回原题：**题图中的开关状态和导线接点才是判断依据；“手电筒亮灭”只帮助想象路径是否接通。先描有效路径，再写电流、电压关系，不猜测图上看不清的接点。[电路机制](phenomena-electricity.md)

**独立检查题：**在同一张题图中只改变一个开关的状态：原来写下的“各处电流相同”还能用吗？让学生先重画有效路径并指出依据；未给出具体图时，不预设答案。

## 卡片外的题目怎样处理

没有现成卡片时，仍按六个动作现场建立一个最小场景：选与本题**同一个研究对象或同一种变化**的安全观察；画变化前后；让学生指出可见差别；再命名概念与题目条件。若暂时找不到准确的感性场景，直接承认该关系需要图示或数据观察，用题目已有实验图或坐标图做观察对象，不编造个人体验。抽象关系必须放在可见差别之后。
