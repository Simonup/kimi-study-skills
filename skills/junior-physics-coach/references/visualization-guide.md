# 物理可视化、多模态与比喻规则

选择能直接解决当前卡点的一种机制主呈现。媒体不是装饰：学生必须能从中指出研究对象、固定条件、改变的条件、作用方向、过程与结果。答案表只回答“填什么”，不能解释“为什么”；多小问实验题先呈现过程对比，再用短表核对答案。已有清晰题图且工具允许标注时，先在原图上标；题图缺失、模糊或比例不可靠时画自制示意图，并明确“示意图，不按比例”。需要精确关系的受力图、光路图、电路图与坐标图用可核验的 SVG 或常规绘图工具；不让生成式插画替代物理作图。

## 按卡点选择模态

先说清孩子要观察或比较的**一个变化**，再检查当前平台能否在这轮对话中制作并显示相应媒体。完整解答时，展示媒体后由教练直接指明关键差别，用文字接回题目条件并继续讲完各小问；独立检查放在讲解末尾。学生明确只要提示时，才可请她先指出差别并等待回答。不能播放或显示时，退回同一机制的静态分帧或带标签的文字图，不声称媒体已经生成。

| 学习卡点 | 主呈现与必须看见的关系 |
|---|---|
| 力的方向、液面深度、光路或电路连接 | 准确标注的静态图；看清对象、箭头、路径、单位或刻度 |
| 运动、热变化等先后过程 | 可暂停的短动画或两到三帧；每帧固定观察对象并标出改变的量 |
| 对照实验中只改变一个条件 | 单变量交互演示；显示固定量、可调量及结果，模拟值与题目数据分开 |
| 音调、响度等听觉差别 | 可播放的音频对比；说明合成或实录来源，控制未研究的响度等条件 |
| 媒体不可用或不比文字更清楚 | 带标签的静态过程图加短段解释；不为多模态添加无关素材 |

动画和交互要有暂停、重复或逐帧查看的办法；播放完一遍就消失、无法核对条件的呈现不适合作为唯一证据。图片、视频、音频或模拟都不能凭外观补造题目没有给的读数。模拟条件与本题不一致时，明确失配处，不能以模拟结果替代题目证据。

## 先决定画什么

| 当前卡点 | 一张主图应展示 | 必查标记 |
|---|---|---|
| 作用对象与受力方向 | 同一研究对象的受力图 | 每根箭头的施力者、力名、方向；运动箭头与力箭头分开 |
| 前后状态、能量或物态 | 两到三帧过程图或短因果箭头图 | 初态、改变的条件、中间过程、末态；物质流与能量流分开 |
| 反射、折射、成像 | 光路图 | 界面、法线或主轴、焦点、入射/出射方向、实线与虚线 |
| 串并联与仪表 | 节点—路径图或标准电路图 | 电源极性、闭合回路、开关状态、电表跨接的两个节点 |
| 速度、密度、欧姆关系 | 坐标图 | 横纵轴物理量、单位、刻度、图例、读数点；不要默认横轴是时间 |
| 多组探究实验 | 同一起点分叉的过程对比图 | 固定量、每组改变的量、作用方向、可见结果；实测与推理分开标 |
| 一个定量关系 | 两列表或简短算式链 | 每个数的单位、这一步依据、是否已统一单位 |
| 原理会讲却不会做题 | 两列“题目证据／物理含义与动作”表 | 原题中的原句或图示、规律前提、第一步和条件变化 |
| 两个概念混在一起 | 两列“这个概念／它负责回答的问题”表或一条关系箭头 | 每个概念的对象、单位、前提；箭头是因果、定义还是比较 |
| 追问“为什么”却缺少直观画面 | 两至三帧同一对象的前后状态 | 每帧写可见或可感变化、改变的条件；先画场景，再写抽象规律 |

面向学生的表格最多两列、六行；超过时拆成两轮或把详细步骤写成短段。机制主呈现与小答案表可并列使用，前者解释过程，后者只供核对；相同信息不要同时用复杂媒体、大表和长文字重复三遍。媒体后解释关键箭头、画面变化、声音差别、坐标点或每一行，不让学生自己猜含义。

### 多组实验：把“相同、改变、看见、推理”画在一起

先在图的共同起点写**保持相同的条件**，再为每一组画“改变的条件 → 谁对谁产生什么作用 → 哪个量怎样变化 → 看得见的结果”。有理想条件时，用虚线或“推理”标签另起一行，不能画成第四组实测数据。图旁用白话解释最容易跳过的箭头，填空答案放在过程解释之后。

以小车滑过毛巾、棉布、木板为例，若题目只给远近而不给测量值，画示意过程，不按横线长度冒充实测距离：

```text
共同起点：同一辆车、斜面同一高度由静止释放 → 进入水平面时速度相同
         ├─ 毛巾：较粗糙 → 向后的阻力较大 → 减速较快 → 停得较近【观察】
         ├─ 棉布：居中   → 向后的阻力较小 → 减速较慢 → 停得较远【观察】
         └─ 木板：较光滑 → 向后的阻力更小 → 减速更慢 → 停得最远【观察】
         ··· 阻力若为零 → 水平方向不再被阻力减速 → 沿直线匀速前进【推理，未实测】
```

解释两处容易误解的箭头：**同一高度由静止释放**用于排除“木板那次本来更快”的解释；**阻力朝后**才使向前运动的小车慢下来，阻力减小时变慢的过程放缓。理想行仍有竖直方向的重力和支持力，它们相互平衡；“阻力为零”不是“物体受到的所有力都消失”。若木板上的车滑出板外，图不能把板边当成停止点；要延长同材质水平面或统一降低三次释放高度再测。

### 原理到考题的两列桥

当学生说“课上听懂，题目不会做”时，给本题最关键的一处对应关系。示例：

| 题目证据 | 物理含义与解题动作 |
|---|---|
| “箱子沿直线匀速运动” | 速度大小和方向不变，可检查受力平衡 |
| “水平方向只有推力和摩擦力” | 水平方向合力为零，因此 `F推=f` |
| 改为“逐渐加速” | 平衡前提消失，原等号不能直接沿用 |

图表只承担“题目文字如何变成物理判断”的功能；因果机制仍须用紧邻的短句说清，不把等号当成解释终点。

### 深化追问先画可感的前后变化

学生追问“为什么／凭什么”时，先选与原题同一对象或同一种变化的真实经历、安全桌面观察，或准确的过程图。第一帧标初态，第二帧标条件怎样变，第三帧标结果；在每帧下写“能看见、听见或感觉到什么”。随后用一句话解释是谁让哪个量改变，最后才画关系箭头并接回题目原句。若只需对比两个状态，就只画两帧，不为凑帧数编造过程。

例如讲匀速时 A 为什么不需水平摩擦力，可用“车起步时向后晃／平稳直行时不持续晃／刹车时向前倾”三帧。标明身体相对车厢的感觉，并说明真实车厢仍可能有空气阻力与颠簸；题目不计空气阻力，讨论的是平稳直行那一帧。不要在这三帧之前先画“匀速 → 合力为零 → 摩擦力为零”的抽象箭头。

### 概念关系图与醒目标记

概念之间只画本题需要的一条关系。箭头旁写关系词，例如“由……决定”“在……条件下相等”“先判断……再计算”；不要只画 `A → B` 让学生猜。要辨析两个词时，用两列表：左列写概念，右列写它回答的问题及本题对应量。三个概念串在一起时，先用一句话解释前两个，再加第三个；不把多个新名词堆在一张网状图上。

**加粗**只突出本轮关键条件或结论；用 `🟨 **关键一句：……**` 做跨平台可见的黄色提示，每轮最多两处。当前界面确实能渲染黄色文字高亮时才使用该功能；无法确认时保留 `🟨`，不输出可能原样露出的 `<mark>` 或 `==...==`。学生说“看着乱”时，删去次要标记，只留一张图、一句标记和当前需要的算式。

## 受力图

1. 写明“以谁为研究对象”；将研究对象画成简单方块或点，不必临摹外形。
2. 对每一个已确认的作用，标出“谁对它的什么力”和方向。若题设不足以判断摩擦方向，先标待定并解释要补哪一条件。
3. 图上“物体往右运动”的运动箭头与“推力向右”的受力箭头用不同位置或线型；不把惯性画成力。
4. 只有已知大小或平衡关系时才用相等箭长，平常标“示意图，不按比例”。

示意：`向上 F浮（水→物块） | [物块] | 向下 G（地球→物块）`。这一行仅表示两种作用，不自动表示它们相等；只有漂浮静止等平衡条件成立才写等号。

## 光路图

- 在反射、折射处先画界面与法线，再画从光源到界面、再到眼睛或屏幕的传播方向；角度均从法线量。
- 实际传播光线用实线、反向延长线用虚线；镜后虚像、凸透镜焦内虚像不能画成真实光线会聚。
- 透镜先确认题目给出或可确定的焦点与物距，才画特殊光线。题目没有精确焦距时不从插画比例量取。
- 每次作图后，用一句话读回“光从哪里来，在哪里改变方向，谁收到了它”。

## 电路图

- 把理想导线连通的各点先归成节点，再沿电源两端寻找完整路径。元件图标遵循学生教材的标准符号；看不清交叉处有无连接点时暂停判串并联。
- 先标开关的当前状态，再标电流表所处支路与电压表跨接的节点。不要让画图工具自动把两条交叉线认作相连。
- 电源直接被低电阻导线或电流表跨接时先判短路，不继续按普通串并联公式计算。
- 如果只能用纯文本，优先写“节点 A—元件—节点 B”的路径列表，避免用字符线条画出含糊的接线。

## 坐标图与数据图

- 横轴、纵轴都写物理量及单位，例如 `时间 t/s`、`路程 s/m`；零点与每格刻度要清楚。只有两个点时先描述这两点，不画未经证实的曲线走势。
- 数学斜率的单位是“纵轴单位÷横轴单位”。`m-V`、`I-U`、`U-I` 交换坐标轴会改变斜率所代表的量。
- 使用程序绘图时用题目原始数据；缺失数据留空，不用想象数据补点。理论曲线须标“理论模型”，实测点须标“题目数据”。
- 图中多条线时，每条线对应的物体、材料或实验组写在图例里；不能只靠颜色区分。

## 互动演示

互动只用于“改变一个条件、立即看到哪个结果随之变化”的问题，例如调节电阻看 `I-U` 关系、改变物距看像位置、改变接触面积看压强模型。开始前写明固定量和可调量，演示后问学生预测未试过的设置。若引用 [PhET](https://phet.colorado.edu/en/simulations)或 [kidslab](https://github.com/talkincode/kidslab)，链接到实际已存在的具体演示；不要宣称计划中的课件已上线。模拟是简化模型，参数或边界不符合题目时不可用其画面判本题答案；复制或改造第三方素材前查 [来源与许可](source-map.md)。

## 比喻使用合同

1. 先讲物理对象与变量，再引入一个学生熟悉的比喻。若学生尚不知道对象，先用图定对象。
2. 明确写“它只对应____关系”。例如“同一路口每分钟通过的人数”只对应稳定电流的流率，不对应电压、能量或电子路径。
3. 接着写“真实物理中还要看____”；回到题目条件、单位、方向或实验数据。
4. 学生沿比喻得出错误结论时，撤回比喻，换成对象图或因果链；不为保护比喻强行解释物理。

回答中的图与比喻要有教学作用。单一事实、一个单位换算或学生已明确掌握的关系，直接短答即可；学生说“还是不懂”时改画卡住的那一箭头，不重复整张大图。
