# 初中物理解题与书写方法

这是给教练检索的“条件 → 规律 → 书写”手册，不是让学生背整张公式表。先读题目中的研究对象、状态、已知与所求，再选一条能解释**为什么适用**的主路。学生说“课上懂了却不会做题”时，看 [原理到考题的桥接](principle-to-problem-bridges.md)，把题目原句或图示接到规律前提；若她接着追问“为什么”，先用 [感性场景与深化追问](sensory-anchors-for-followups.md) 中的可感前后变化补足背景，再回当前题。题目没有提供的条件不要补造；学生用另一条正确路径时沿她的路径核查。完整解答的末尾必须给“解题方法”和“同类题怎么写”，只提示且尚未解完时不提前揭示它们。

## 每道题共用的六步

1. **找对象与过程：**研究的是哪件物体、哪段时间、哪一段电路或哪个实验组？变化前后状态是什么？
2. **整理条件：**用原题的词与数值列“已知／所求”，标单位、方向、约束。示意图上没写的关系不当作已知。
3. **把题目译成原理：**圈出允许某条规律成立的原句、图示或数据，写出“题目证据 → 物理状态／模型前提”。没有证据时不自行补条件。
4. **选依据：**用一句因果话解释该规律为何适用，再写出“原理 → 本题关系”；前提不满足就换路，不能仅凭关键词套公式。
5. **画或列关系：**选一张最能解释当前难点的受力图、光路图、电路路径、坐标图、过程图或两列表；再列式或按证据推理。
6. **核验与归纳：**单位、数量级、方向、图示和答案一致吗？用一个关键条件的变化检验“这条方法何时需要改”。

## 题型入口：看到的是条件，不是关键词

| 可核查的条件与目标 | 主方法与动笔顺序 | 用前必查 |
|---|---|---|
| 一段或多段运动，求快慢、时间或路程 | 分段列路程与时间 → 求总量 → 用 `平均速度=总路程/总时间` | 停顿是否计时；路程与位移是否混淆；单位是否统一 |
| 图中只有质量和体积或排水法读数 | 读质量、前后液面体积差 → 求物体体积 → `ρ=m/V` | 量筒读数单位；物体是否完全浸没、无吸水或溶解 |
| 物体静止或匀速直线运动，求某个力 | 选研究对象 → 逐力写施力者与方向 → 平衡方向上列大小关系 | “匀速”是否明确；是否漏掉斜面、绳、接触力 |
| 接触面受压，求压强；静止液体某深度求压强 | 前者辨认垂直压力与实际受力面积；后者辨认液体密度与竖直深度 | 压力不自动等于重力；`h` 不是容器高度或斜长 |
| 浸入液体求浮力或判断浮沉 | 先求排开体积与液体密度；或在静止漂浮时用平衡求浮力 | “浸没／半浸／漂浮／沉底”不相同；沉底还可能受底部支持力 |
| 力臂、滑轮、功、功率或机械效率 | 画力与位移；分清输入、输出；按相应平衡式或功的定义列式 | 力臂为垂距；`s` 与 `h` 是否不同；是否有额外功 |
| 灯泡、电阻、电表与开关 | 标节点 → 沿导线追踪闭合回路 → 判串并联 → 标各电表测量对象 → 列电流电压关系 | 是否短路/开路；电源或元件是否理想；所求为实际还是额定 |
| 曲线或数据表 | 先读题名、横纵轴、刻度、单位与图例 → 找两点或区间 → 计算或描述关系 | 横纵轴是否交换；某段是平、升、降还是回返；数据是否支持因果 |
| 实验变量与结论 | 研究问题 → 改变的量 → 保持相同的量 → 测得的量 → 数据对比 → 有范围的结论 | 是否有真正对照；是否只改变一个关键因素；结论是否超出数据 |
| 镜像、折射或凸透镜 | 画界面、法线、主轴、焦点与已知光线 → 按规律作图 → 判实际光线或反向延长线 | 角度从法线量；虚线不是光传播；焦点及物距要从图/题获得 |

## A. 计算题怎样写：先解释式子的来历

**书写模板：**

> 研究对象是____，取____这段过程。题目给出____，要求____。因为____条件满足____规律，所以____。先把____换算为____，代入得____。结果单位为____，与题意____。如果____条件改变，原式中的____就要重新确定。

- **平均速度：**`v平均=总路程/总时间`。相等路程的两段，速度不同，不能直接把两段速度作算术平均。路程 `s` 用 m、时间 `t` 用 s 时，速度是 m/s。若题目以 km/h 给出，先统一单位。
- **密度：**`ρ=m/V`；量筒的 `mL` 与 `cm³` 等量；计算前区分容器中液体体积与物体排开体积。物体吸水、溶解、漂浮或未完全浸没时，排水读数未必是整件物体的体积。
- **固体接触压强：**`p=F/S`，`F` 指垂直于接触面的压力。若物体水平静放且竖直方向仅受重力和支持力，可由平衡求压力大小等于重力；换成斜面或外力作用不能直接写 `F=G`。
- **液体压强：**静止且密度近似不变时，可用 `p液=ρ液gh` 算液面以下 `h` 处相对液面的压强。若问总压强，还要核对是否需加液面上方气体压强。
- **浮力：**`F浮=ρ液gV排`；漂浮静止时可由竖直方向平衡得 `F浮=G物`。两式来源不同，前者看排液，后者看运动状态。
- **电学：**`I=U/R` 只在题目允许近似恒定电阻且条件已核实时使用；`P=UI` 是功率，`W=Pt` 是一段时间的电能。小灯泡若未说明恒定电阻，先检查是否给了额定值或实际测量数据。

### 完整示例 A1：两段路程的全程平均速度

题：小车先用 `20 s` 行驶 `100 m`，再用 `10 s` 行驶 `100 m`。全程平均速度是多少？

| 分段 | 路程／时间 |
|---|---|
| 前一段 | `100 m／20 s` |
| 后一段 | `100 m／10 s` |
| 全程 | `200 m／30 s` |

**原理接到题目：**平均速度描述整个过程的快慢，定义中的路程和时间必须对应同一段过程；题目问“全程”，因此把两段路程与两段时间分别合并。全程平均速度 `v=200 m÷30 s≈6.67 m/s`。两段速度为 `5 m/s` 与 `10 m/s`，直接平均成 `7.5 m/s` 不对，因为第二段只持续 10 秒。**解题方法：**先合并总路程与总时间，再取比；停顿也要计入题目规定的总时间。**同类题怎么写：**“列各段路程和时间 → 合并全程 → 写平均速度定义式 → 代入统一单位 → 比较结果”。[定义核对](https://openstax.org/books/physics/pages/2-2-speed-and-velocity)

## B. 受力与平衡题怎样写

**书写模板：**

> 以____为研究对象。它受到____施加的____力，方向____；还受到____力，方向____。因为题目给出它____（静止／匀速直线运动），所以____方向合力为零。由此得____。这条等式成立的前提是____。

先画研究对象，再从接触、重力、绳、液体等已知相互作用逐一找施力者。只用明确的静止或匀速直线运动判平衡；转弯、速度变大或变小均不是平衡。摩擦力方向要看接触面相对运动或相对运动趋势，不能仅看整件物体向哪走。

### 完整示例 B1：漂浮木块的浮力

题：质量 `0.20 kg` 的木块静止漂浮在水面，取 `g=10 N/kg`。求浮力。

**原理接到题目：**木块受水向上的浮力；“静止漂浮”说明木块保持平衡，且竖直方向只有重力和浮力时两者大小相等。以木块为对象，`G=mg=0.20 kg×10 N/kg=2.0 N`，故 `F浮=G=2.0 N`。本题不需要排开水体积。**解题方法：**“漂浮静止”提供平衡条件；质量先转成重力。**同类题怎么写：**“选木块 → 画重力和浮力 → 写静止平衡 → 求量并核单位”。若改成沉底，底部支持力可能参与平衡，不能再直接写 `F浮=G`。[浮力依据](https://openstax.org/books/college-physics/pages/11-7-archimedes-principle)

## C. 图像与表格题怎样写

**书写模板：**

> 横轴是____，单位____；纵轴是____，单位____。从图中读得____。在____区间内，____增加／减小／不变。依据____的定义或题设条件，可得____。图只支持____，不能推出____。

- `s-t` 图若 `s` 为累计路程，某段越陡表示该段路程增长越快；水平段表示累计路程不变。若纵轴是位置，图线下降表示位置坐标减小，不等于路程“倒退”。
- `v-t` 图先看 `v` 代表速度大小还是带方向的速度；中学题给稳定的分段速度时，用“速度×时间”的矩形计算各段路程。不要见到任意曲线就让初中生套面积法或微积分。
- `m-V` 图在横轴体积、纵轴质量时，同一均匀材料的斜率 `Δm/ΔV` 为密度；交换坐标轴则斜率变为 `ΔV/Δm`。
- `I-U` 图横轴 `U`、纵轴 `I` 且元件近似欧姆性时，斜率是 `1/R`；`U-I` 图交换两轴后斜率是 `R`。弯曲图线不能用一条固定斜率代表所有工作状态。
- 实验图只有相关变化时先描述“在给定条件下，随 A 增大 B 怎样变”；要说 A 导致 B，须核对实验设计是否排除了其他变化因素。

## D. 电路题怎样写：先追路径，后列公式

**书写模板：**

> 先把理想导线连通处标为节点____。由电源一端沿____路径到另一端，发现____个分支，因此____与____是____联。电流表位于____路径，测____；电压表跨接____两点，测____。由____联规律和____条件得到____，代入得____。最后检查开关状态、短路与单位。

注意开关切换后要**重画当前状态**；不能把开关闭合前后的电路关系混在一起。对小灯泡不可默认恒定电阻；如果题目只给额定电压和额定功率，可算额定状态的电流，但不能直接推出任意实际状态亮度。任何短接电源或电流表并接电源的图先停下来判风险与题意。

### 完整示例 D1：两电阻串联

题：`R₁=2 Ω`、`R₂=4 Ω` 串接在理想 `6 V` 电源上，求回路电流及各电阻两端电压。假定两电阻在该条件下为欧姆元件。

**原理接到题目：**“串接”与电路中只有一条闭合路径相对应，因此两个元件中电流相同；题目还说明两电阻为欧姆元件，才可用给定电阻与电压求电流。总电阻 `R总=2 Ω+4 Ω=6 Ω`，`I=U/R总=6 V÷6 Ω=1 A`。于是 `U₁=IR₁=2 V`，`U₂=IR₂=4 V`，检查 `U₁+U₂=6 V`。**解题方法：**先判路径和串联，再求总电阻与电流，最后分配各元件电压。**同类题怎么写：**“追闭合路径 → 判串并联 → 写同流/同压关系 → 列欧姆式 → 用总电压或总电流反查”。若改成并联，首先变化的是连接关系，不能沿用串联总电阻式。[串联依据](https://openstax.org/books/physics/pages/19-2-series-circuits)

## E. 实验题怎样写：让结论只走到证据支持处

**书写模板：**

> 要研究的问题是____。实验中主动改变____（自变量），测量____（因变量），保持____等条件相同。由第____组和第____组数据可见____。因此仅在____条件与测量范围内，可以说____；题目数据还不能证明____。

先读仪器、量程、刻度、零点与单位，再读数。观察、测量、推断分开写。没有对照组时说明“材料未提供对照组”；不能替题目补造。只做一次实验不能断言关系稳定；多次测量的目的要看实验是减小随机误差，还是探查规律在不同条件下是否成立。

### 完整示例 E1：压力作用效果与受力面积

题：同一块海绵上放同一块长方体，分别以大面和小面接触。记录显示小面接触时海绵下陷更深。怎样写结论？

自变量是接触面积；因变量用海绵下陷程度作“压力作用效果”的观察指标；用同一块物体和同一块海绵，使物体重力及材料条件保持一致。数据表明**在该装置中、压力相同的条件下**，受力面积较小时下陷更深，可据此说明压力作用效果更明显。不能说所有材料都会下陷同样深，也不能把下陷深度直接当压强数值。**解题方法：**先找唯一改变的条件，再把观察与结论分开。**同类题怎么写：**“目的 → 变量 → 不变量 → 观测量 → 两组差异 → 限定范围的结论”。

### 完整示例 E2：阻力对小车运动的影响

题：同一辆小车每次从同一斜面的同一高度由静止滑下，在铺毛巾、棉布和裸木板的水平面上分别前进。题图显示木板上滑得最远，问控制条件、阻力怎样改变速度，以及“阻力为零”的推理。

先画[同一起点分叉的过程图](visualization-guide.md#多组实验把相同改变看见推理画在一起)，再逐项解释：同车、同高、静止释放使小车进入水平面时速度相同，这排除了“木板上滑得远是因为一开始更快”的解释。三次主动改变的是水平接触面的粗糙程度；小车向前运动时，接触面给它的阻力朝后，阻力越小，向前的速度减小得越慢，停下前走得越远。题图上的三种距离是**观察**；“阻力若为零，将保持匀速直线运动”是沿这一趋势作的**理想推理**，不能冒称做过零阻力实验。竖直方向仍有重力与支持力平衡，不写成“完全不受力”。

若小车滑出木板，不能把木板边缘当作停止位置；换更长的同材质木板，或在三次实验中统一降低释放高度再比较。讲这题时先让孩子看见“同一入口速度，不同的变慢过程”，再给填空答案；不要用“题号—答案”表取代这些过程。**解题方法：**先查起步条件是否相同，再找唯一改变的水平条件，读滑行远近，解释阻力怎样改变速度，最后把实测和理想推理分开。**同类题怎么写：**“控制起步 → 改接触面 → 读运动结果 → 解释受力与速度变化 → 标出推理边界”。

## F. 光学作图与概念解释怎样写

**书写模板：**

> 光从____出发，经____界面到达____。先画界面与法线／主光轴，再按____规律画实际传播光线（实线）。____位置是反向延长线交点（虚线）／真实光线交点（实线），所以是____像。图示以题目所给角度、焦点和距离为准。

反射角、折射角都是与**法线**的夹角。平面镜虚像的镜后线段为反向延长线，不是光走过的路径。凸透镜先确定物距与焦距关系，再用两条独立的特殊光线定位像；题目未给焦距时不凭插画大小估计。画不准时用文字逐步描述光线，不生成貌似精确但条件错误的图。

## G. 讲现象或辨析概念怎样写

**书写模板：**

> 观察到____。在____条件下，____对____发生____作用，使____先变化；这一变化再导致____，所以出现____。若改动____条件，前面第____步不再成立／会改变，因此结果可能____。

遇到“惯性、压强、能量、热量、功率”等名词，不把名词当解释终点。至少说出“谁作用于谁”或“哪个量从哪里转移到哪里”，并给一条能验证或推翻原解释的条件变化。比喻后补一句“这个比喻只说明____，真实情形还要看____”。

## 结束语的两段检查

- **解题方法：**写本题真正起作用的条件、所用关系为何适用、最容易写错的一步。不能只列公式或复述答案。
- **同类题怎么写：**给由“研究对象／条件／目标量”界定的类别，写 4—6 个动作组成的答题顺序，再写一个会使原方法失效或需修改的边界。没有足够依据归类时，写“这道题下次先检查____”，不硬贴题型标签。
