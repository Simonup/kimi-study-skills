# 事件与历史解释资料的接收格式

此文件用于以后接收用户提供的教材、书籍、论文、史料、网页或个人笔记。当前没有具体事件卡。原始材料保留出处；整理卡只记录已经核实的内容。

## 接收与核验步骤

1. 记录材料的标题、作者或机构、出版或更新日期、版次、可定位页码或链接，以及用户希望覆盖的年级与章节。
2. 区分材料类型：教材或课程文件、原始史料、研究著作、教学参考、个人笔记。个人笔记只能作为待核对线索。
3. 对每条断言回到原文定位，核实其时间、人物、措辞和适用范围。未找到原文的断言标“待核验”。
4. 若教材叙述、史料与学术解释不一致，分别记录，不改写为单一确定结论。
5. 经核验后再建立事件卡；引用精确日期、数字和原话时附可追溯出处。

## 事件卡字段

| 字段 | 填写要求 |
| --- | --- |
| 卡片 ID / 标题 | 稳定、简短、能区分同名事件。 |
| 教材定位 | 出版社、版次、年级、册、课、页；材料没有时填“未提供”。 |
| 时间与空间 | 写可核实的时间范围和地点；无法精确时保留原来源的范围。 |
| 关键人物与行动 | 只写与该事件直接相关且有出处的内容。 |
| 背景与原因 | 分开记载背景条件、直接诱因与解释机制，给每条标出处。 |
| 经过与结果 | 按时间顺序写可核实事实，不把顺序当作因果证明。 |
| 影响与争议 | 标明影响对象、时间尺度、解释者与不同观点。 |
| 史料证据 | 原始史料的作者、年代、体裁、目的、可定位出处和可信度限制。 |
| 核心素养入口 | 选择适用的时空观念、史料实证、历史解释、家国情怀；如使用唯物史观，写清解释对象与证据。 |
| 常见误解 | 具体错误表述、错因及纠正证据。 |
| 练习问题 | 一道理解题和一道证据或解释题，并附判定要点。 |
| 核验状态 | “待核验”或“已核验”，附核验日期与来源。 |

## 使用边界

- 卡片中的“史实”“材料信息”“研究者解释”“课堂答题口径”分开写。
- 不从来源没有覆盖的时期、地区或人群外推结论。
- 用户追加资料时在原有卡片上注明新增证据与修订原因，保留可追溯的旧出处。
- 未收到材料前，知识卡目录保持空白；教学流程仍可处理学生现场提供的题目与课本内容。
