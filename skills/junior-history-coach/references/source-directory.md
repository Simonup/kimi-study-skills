# 初中历史通识与史料来源目录

本目录只负责把问题路由到可核查的站点，不预存事件结论。使用时先确定本题教材版本和问法，再打开站内的具体课、藏品、文献、地图图层或数据页，记录标题、作者或机构、年代、版本及链接。网站的质量不能自动保证每个条目都正确；具体断言仍须核对原出处。

## GitHub、地图和历史数据

| 来源 | 用于 | 使用边界 |
| --- | --- | --- |
| [OpenHistoricalMap](https://www.openhistoricalmap.org/)及其 [GitHub 数据仓库](https://github.com/OpenHistoricalMap/data) | 观察历史地名、道路与边界的时间变化，寻找可下载的地理数据。 | 众包项目；逐项检查地图要素的日期和来源，不能把地图轮廓当作无需核实的史实。 |
| [Awesome Historical Maps（GitHub）](https://github.com/stark1tty/awesome-historical-maps) | 按地区寻找图书馆、档案馆和地图馆藏入口。 | 这是导航清单，不是史料；进入清单所指的馆藏原站核对每张地图。 |
| [Our World in Data](https://ourworldindata.org/)与其[人口数据来源说明](https://ourworldindata.org/population-sources) | 查近现代及长时段人口、健康、教育等量化趋势和来源方法。 | 历史早期数据多为估计，国界口径与数据拼接会影响比较；引用图表的原始数据源和方法。 |
| [Gapminder Systema Globalis（GitHub）](https://github.com/open-numbers/ddf--gapminder--systema_globalis) | 查历史统计数据的开放数据文件及版本。 | 只用于数据题或趋势解释；先看变量定义、年份与原始数据出处。 |

## 选源次序

1. **学校作业与考试：**先看学生提供的教材和题目，再核对同版教材、课标；扩展资料只用来讲清背景或核实疑点。
2. **事件通识：**先用有署名和参考文献的综述建立轮廓，再查对应博物馆、档案馆或研究资料；对争议结论标明解释者。
3. **原始史料：**优先进入馆藏原件页；记录作者、制作年代、用途及保存机构。区分“史料当时怎样说”和“后来怎样解释”。
4. **地图与统计：**核对时间切片、地名、边界定义、数据口径与来源；两张地图或两组数字口径不同则分开呈现。
5. **GitHub 项目：**用作工具、数据入口或导航；没有原始出处、版本和许可信息的仓库不进入事件知识卡。
